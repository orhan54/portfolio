Projet 1 : Gestionnaire de tâches (Full Stack)

Contrairement aux autres projets de ce portfolio, celui-ci intègre un véritable back-end PHP orienté objet connecté à une base de données MySQL. L'application suit une architecture MVC construite de zéro (sans framework), avec une séparation stricte via le pattern DAO/Entité et des requêtes SQL préparées pour sécuriser les échanges avec la base. Le CRUD est complet : création, lecture, modification et suppression des tâches, avec une interface stylisée en Tailwind CSS.
